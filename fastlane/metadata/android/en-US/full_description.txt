QR Code Displayer generates a clean, easy-to-scan version of any QR code.

The app works like this:
* You select an image containing a QR code on your phone or "share" it to this app.
* The app decodes the original code using math!
* A brand new, high-resolution QR code is generated containing the exact same content.
* The new code is drawn with black edges on a white background.
* You then have the option to enter display mode, where screen brightness is maximized and stays awake to assist with scanning.
* You also can give your new QR code a title and save it to use later.
* Or even see what is the content of the qr code and copy it!

This app is fully open-source, contains no ads or unnecessary permissions, and processes all data entirely offline on your own device.
